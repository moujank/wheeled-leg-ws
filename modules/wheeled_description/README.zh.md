# wheeled_description

[English](README.md) · [上级目录](../README.md)

该目录预留给机器人描述真源数据使用，目前除了文档之外没有实际实现文件。

## 预期职责

- 维护统一的机器人命名、坐标系约定和关节定义
- 维护 CAD 到 URDF，或源 URDF 到派生资产之间的关系
- 说明训练、MuJoCo、部署三侧资产的派生链路
- 在导出到其他目录前，集中管理描述变更的版本来源

## 当前状态

- 这里还没有保存真正的源描述包
- 当前导出的资产主要位于 `assets/` 和 `modules/wheeled_mujoco/asset/`

如果后续启用该模块，重点应是说明这些导出资产如何生成与校验，而不是简单复制派生文件。
