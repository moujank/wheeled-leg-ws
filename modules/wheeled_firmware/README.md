# wheeled_firmware

This directory is reserved for embedded firmware related to the wheeled-leg platform. It currently contains documentation only.

## Intended scope

- motor controller firmware
- communication board or bridge MCU firmware
- sensor bring-up, calibration, and low-level protocol handling
- board-specific build instructions and flashing procedures

## Current status

- no firmware project, toolchain config, or board support package is present yet

Keep future additions focused on code that runs on microcontrollers or dedicated embedded boards. Host-side robotics applications should live elsewhere.
